# Syed's Tees — E-Commerce Front-End

A front-end e-commerce storefront concept for **Syed's Tees**, focused on a premium men's T-shirt shopping experience. The interface is built with HTML, CSS, JavaScript, and Bootstrap.

## Overview

The project demonstrates a product-focused storefront layout with promotional content, category navigation, product presentation, and shopping-oriented UI components.

## Interface highlights

- Promotional announcement bar and storefront navigation
- Product categories including plain, printed, and premium T-shirts
- Product cards with pricing and sale/new-item badges
- Product detail modal layout
- Review and rating presentation components
- WhatsApp contact entry point
- Responsive styling for desktop and mobile screens

> This repository is a front-end project. Do not assume checkout, payment processing, order management, or a production backend is configured.

## Technology stack

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome
- Google Fonts (Jost)

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/ghinaulhasan/E-commerece-web.git
   cd E-commerece-web
   ```
2. Open `index.html` in a browser, or use the VS Code Live Server extension.

External libraries and fonts are loaded from CDNs, so an internet connection is needed for those assets.

## Main files

- `index.html` — storefront markup and styles
- `style.css` — additional stylesheet, if used by the page
- `script.js` — client-side interactions
